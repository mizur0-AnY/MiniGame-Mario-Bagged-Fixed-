# Super Mario Bros — исправленная версия

Это копия игры, в которой **исправлены все 16 намеренно сломаных багов**.
Игра работает корректно: подсказок по багам нет, все механики в норме.

Оригинальная версия (игра-лабиринт, где баги нужно искать и чинить) лежит рядом,
в папке `SuperMarioBros-CSharp-Remake-main`.

## Что исправлено

| № | Баг | Как было | Как стало |
|---|-----|----------|-----------|
| 1 | Управление | Right двигал влево | Right двигает вправо |
| 2 | Прыжок | втрое выше нормы | обычная высота прыжка |
| 3 | Таймер | уменьшался на 3 в секунду | уменьшается на 1 в секунду |
| 4 | Фаербол | летел в сторону, противоположную взгляду | летит туда, куда смотрит Марио |
| 5 | Зелёный гриб | отнимал жизнь | добавляет жизнь |
| 6 | Граница смерти | Марио умирал от удара о небо | смерть только в яме под уровнем |
| 7 | Счёт | отнимал очки за убийство | добавляет очки |
| 8 | Монета из блока | давала 5 монет | даёт 1 монету |
| 9 | Фаерболы и панцири | исчезали, враг оставался жив | уничтожают врага |
| 10 | Флагшток | уровень не заканчивался | уровень завершается |
| 11 | Блок с предметом | выдавал предмет бесконечно | выдаёт предмет один раз |
| 12 | Стены | Марио проходил сквозь них | физика выталкивает из стен |
| 13 | Бой | враги были неуязвимы сверху | приземление сверху убивает врага |
| 14 | Урон | Марио становился сильнее | Марио уменьшается |
| 15 | Монета с пола | давала 10 монет | даёт 1 монету |
| 16 | Камера при беге | ехала назад при беге вправо | едет за игроком |
| 17 | Камера при ходьбе | ехала назад при обычной ходьбе | едет за игроком |

Про баг №17: он не был частью задания с 16 подсказками — это настоящий дефект
исходного кода. В методе `moveRight` границы отрисовки (`frontX`, `backX`) двигались
вперёд, а `offset` уменьшался, то есть камера ехала назад. Исправлено на `offset += speed`.

Система подсказок в этой копии отключена (`hintsEnabled = false`): багов больше нет,
показывать инструкции не о чему.

## Управление

| Клавиша | Действие |
|---------|----------|
| ↑ / ↓ | выбор «1 PLAYER» / «2 PLAYER» |
| **Enter** | старт игры |
| ← → или A / D | движение |
| **Space** | прыжок |
| **E** (удерживать) | бег, выстрел (когда Марио «в огне») |
| **F11** или Alt+Enter | полный экран |
| **Escape** | выход из полного экрана |

## Запуск

- Откройте `SuperMarioBros.sln` в Visual Studio и нажмите **F5**
- или дважды кликните `build-and-run.cmd` — он сам пересоберёт игру и запустит
- или готовый файл: `bin\Debug\SuperMarioBros.exe`

## Сборка

- .NET Framework 4.8, Windows Forms, Visual Studio
- Если у вас не установлен .NET Framework 4.8 Developer Pack, проект всё равно соберётся:
  в `.csproj` есть запасной вариант, компилирующий против установленной среды .NET 4.8
